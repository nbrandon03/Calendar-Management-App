Instructions for ClearDay Calendar Application
Created By: CS3307 Group 02 (Nikolas Kiroff, Rosaline Liu, Dinith Nawaratne, Brandon Nguyen, Uday Prashant)
===========================================================================================================

This is a Calendar application prototype implemented in C++ using wxWidgets. Ensure you are in the correct directory of all the files, and have wxWidgets installed and setup properly. Additionally, utilize the terminal to build, run, and clean the application.

Build:
    make

Run:
    ./clearday

Clean:
    make clean
